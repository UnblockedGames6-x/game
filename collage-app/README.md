# Collage Maker

A simple client-side photo collage creator. Works entirely in the browser, no server needed.

## Features

- Upload multiple images via file dialog
- Choose between three grid templates
- Move, scale and rotate images directly on the canvas
- Customize background color and frame borders
- Export your collage as PNG or JPG

## Usage

Open `index.html` in any modern web browser. No build step or server is required.
